# Package index

## All functions

- [`WRSS()`](https://lmaowisc.github.io/WR/reference/WRSS.md) : Compute
  the sample size for standard win ratio test
- [`WRrec()`](https://lmaowisc.github.io/WR/reference/WRrec.md) :
  Generalized win ratio tests
- [`base()`](https://lmaowisc.github.io/WR/reference/base.md) : Compute
  the baseline parameters needed for sample size calculation for
  standard win ratio test
- [`gbc`](https://lmaowisc.github.io/WR/reference/gbc.md) : A subset of
  the German Breast Cancer study data
- [`gumbel.est()`](https://lmaowisc.github.io/WR/reference/gumbel.est.md)
  : Estimate baseline parameters in the Gumbel–Hougaard model for sample
  size calculation using pilot data
- [`hfaction_cpx9`](https://lmaowisc.github.io/WR/reference/hfaction_cpx9.md)
  : A subset of the HF-ACTION study data on high-risk non-ischemic heart
  failure patients
- [`non_ischemic`](https://lmaowisc.github.io/WR/reference/non_ischemic.md)
  : A subset of the HF-ACTION study data on non-ischemic heart failure
  patients with full covariate measurement.
- [`plot(`*`<pwreg.score>`*`)`](https://lmaowisc.github.io/WR/reference/plot.pwreg.score.md)
  : Plot the standardized score processes
- [`print(`*`<WRrec>`*`)`](https://lmaowisc.github.io/WR/reference/print.WRrec.md)
  : Print the results of the two-sample recurrent-event win ratio
  analysis
- [`print(`*`<pwreg>`*`)`](https://lmaowisc.github.io/WR/reference/print.pwreg.md)
  : Print the results of the proportional win-fractions regression model
- [`print(`*`<pwreg.score>`*`)`](https://lmaowisc.github.io/WR/reference/print.pwreg.score.md)
  : Print information on the content of the pwreg.score object
- [`print(`*`<pwreg1>`*`)`](https://lmaowisc.github.io/WR/reference/print.pwreg1.md)
  : Print model information for a proportional win-fractions regression
- [`pwreg()`](https://lmaowisc.github.io/WR/reference/pwreg.md) : Fit a
  standard proportional win-fractions (PW) regression model
- [`pwreg1()`](https://lmaowisc.github.io/WR/reference/pwreg1.md) : A
  test version of pwreg
- [`score.proc()`](https://lmaowisc.github.io/WR/reference/score.proc.md)
  : Computes the standardized score processes
