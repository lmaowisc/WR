Analyze death and nonfatal events together, with their clinical importance built into the method.

In practice
HF-ACTION · recurrent events
# Load the included trial subset
library(WR)
dat <- hfaction_cpx9

# Stratify by age
fit <- WRrec(
  ID = dat$patid,
  time = dat$time,
  status = dat$status,
  trt = dat$trt_ab,
  strata = dat$age60
)
print(fit)
HF-ACTION · covariate adjustment
# Load the regression dataset
library(WR)
dat <- non_ischemic
Z <- as.matrix(dat[, c("trt_ab", "age")])

# Adjust for age
fit <- pwreg(
  ID = dat$ID,
  time = dat$time,
  status = dat$status,
  Z = Z
)
print(fit)

A useful distinction

WRrec() can use recurrent nonfatal events. Standard pwreg() uses the first nonfatal event. Choose the analysis to match the scientific question.
