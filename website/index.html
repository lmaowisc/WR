From comparison

WR brings together two-sample testing, covariate adjustment, and sample size calculation for prioritized composite outcomes.

A useful distinction

WRrec() can use recurrent nonfatal events. Standard pwreg() uses the first nonfatal event. Choose the analysis to match the scientific question.

Prepare data in long format

Use one row per event or censoring record, with a patient identifier and event time.

0
Censoring
1
Death
2
Nonfatal event
HF-ACTION · recurrent events
# Load the included trial subset
library(WR)
dat <- hfaction_cpx9

# Age-stratified recurrent-event analysis
fit <- WRrec(
  ID     = dat$patid,
  time   = dat$time,
  status = dat$status,
  trt    = dat$trt_ab,
  strata = dat$age60
)

print(fit)
RRun in your R session
HF-ACTION · covariate adjustment
# Load the included regression dataset
library(WR)
dat <- non_ischemic
Z <- as.matrix(dat[, c("trt_ab", "age")])

# Adjust the treatment comparison for age
fit <- pwreg(
  ID     = dat$ID,
  time   = dat$time,
  status = dat$status,
  Z      = Z
)

print(fit)
