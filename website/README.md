# WR website homepage

These files supply the custom homepage for <https://lmaowisc.github.io/WR/>. The package reference and vignettes are generated by pkgdown. The GitHub Actions workflow builds pkgdown and then copies these files to the root of the published site.

When WR changes, update the package documentation and the files in this folder together.

The research notebook theme uses UW–Madison's digital Badger Red (`#C5050C`), white (`#FFFFFF`), dark red (`#9B0000`), light gray (`#E1E5E7`), and black (`#121212`). Deep blue (`#17365D`) is a custom accent chosen for WR, not an official UW digital brand color. The same typography and palette are applied to the generated documentation through `_pkgdown.yml` and `pkgdown/extra.css`.
